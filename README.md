
# DS About Us

Site desenvolvido para apresentar os integrantes do grupo por meio de páginas pessoais, permitindo conhecer seus interesses, hobbies, experiências e curiosidades.

A página inicial reúne os perfis de **Gustavo**, **Pedro** e **Fernando Zaia**, com cartões que direcionam para suas respectivas páginas.

## 👥 Integrantes

| Integrante | Página pessoal |
| --- | --- |
| Gustavo | [Acessar perfil](pagina-pessoal/index.html) |
| Pedro | [Acessar perfil](paginas/landing_pedro/pedro.html) |
| Fernando Zaia | [Acessar perfil](paginas/landing_zaia/index.html) |

### Gustavo
Apresenta seus interesses por programação, xadrez, videogames, esportes, músicas e outros assuntos pessoais.

### Pedro
Compartilha curiosidades, hobbies, preferências, lugares que conhece e destinos que deseja visitar.

### Fernando Zaia
Apresenta informações pessoais, interesses por vôlei, jogos, leitura, música, lugares favoritos e sonhos de viagem.

## 🚀 Funcionalidades

- Página inicial com cartões dos integrantes.
- Navegação entre as páginas pessoais.
- Apresentação de informações, hobbies e curiosidades.
- Utilização de imagens para ilustrar os conteúdos.
- Layouts adaptados para diferentes tamanhos de tela.
- Animações e interações em JavaScript em algumas páginas.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** estilização, cores, layouts e responsividade.
- **JavaScript:** interações e animações.
- **Bootstrap 5.3.3:** utilizado na página pessoal do Gustavo.

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/phenriqueangelodesouza-collab/ds-about-us.git
```

### 2. Acesse a pasta

```bash
cd ds-about-us
```

### 3. Abra a página

Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code.

> Mantenha a estrutura original das pastas para que os links entre as páginas e os caminhos das imagens continuem funcionando.

## 🎨 Identidade visual

A página inicial utiliza uma paleta composta por:

- **Roxo escuro:** cor principal do fundo.
- **Amarelo:** destaques e elementos de navegação.
- **Branco:** textos e informações.

Cada integrante também possui uma identidade visual própria em sua página pessoal.

## 🎯 Objetivo do projeto

Desenvolver um site colaborativo utilizando conhecimentos de desenvolvimento web, aplicando conceitos de estruturação HTML, estilização CSS, navegação entre páginas e organização de arquivos.

O projeto permite que cada integrante personalize sua apresentação e pratique habilidades de desenvolvimento front-end.
